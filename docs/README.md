# CODA 設計ドキュメント

Client-Owned Data Architecture（CODA）は、サービス事業者がアプリケーションと処理を提供し、ユーザーが認証情報とデータを所有する共通基盤です。

サービスA・B・Cはそれぞれ独立した事業者が運営します。各事業者は自社のWebアプリ・API・認証設定・署名鍵を所有し、共通プロトコルを通じてユーザー端末のVaultへ個別に接続します。

業務データの変更は、当該サービスへの有効な接続中に、サービスが署名した操作を通じてのみ許可します。ローカル管理画面やオフラインでの直接編集は禁止し、復旧データの利用再開にもサービスの承認を必要とします。
